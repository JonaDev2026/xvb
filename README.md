  XVB Player
</h1>

**XVB Player** is a feature-rich, free, and open-source media player powered by `libmpv`. Designed for ultimate versatility, it seamlessly handles everything from local music, videos, DVDs, and ISO images to IPTV streams (with TV guides and recording) and live RTSP security camera feeds.
