Extended Video Broadcast

A lightweight IPTV player for Linux. m3u playlists, XMLTV guide, recording, favourites. Python on top of libmpv, dark interface, no accounts, no telemetry.

Lettore IPTV per Linux, leggero. Playlist m3u, guida XMLTV, registrazione, preferiti. Python su libmpv, interfaccia scura, niente account, niente telemetria.

What it doesCosa fa

PlaylistsPlaylist

Drop m3u files in a folder or add a URL. Groups become folders, dead channels are skipped, lists from the web refresh every 6 hours.

Metti i file m3u in una cartella o aggiungi un url. I gruppi diventano cartelle, i canali morti vengono saltati, le liste dal web si aggiornano ogni 6 ore.

TV guideGuida TV

Several XMLTV sources at once, plain or gzipped. Current programme under the channel name, a progress line, and a full timeline grid.

Più guide XMLTV insieme, xml o gz. Programma in corso sotto il nome del canale, linea di avanzamento e griglia con la timeline.

RecordingRegistrazione

One click to record, or schedule start and end. Files are named after the programme and sorted per channel and day, playable from the sidebar.

Un clic per registrare, oppure pianifica inizio e fine. I file prendono il nome del programma, divisi per canale e giorno, e si riguardano dalla sidebar.

FavouritesPreferiti

A heart on the controls adds the channel to a red Favourites folder, kept per playlist.

Un cuore nei controlli aggiunge il canale alla cartella rossa dei preferiti, una per playlist.

Video & audioVideo e audio

Quality selection on HLS streams, speed, aspect ratio, deinterlace, picture controls, audio and subtitle tracks, per‑channel audio delay, volume boost.

Scelta della qualità sugli HLS, velocità, proporzioni, deinterlaccia, regolazioni immagine, tracce audio e sottotitoli, ritardo audio per canale, boost del volume.

Four languagesQuattro lingue

English, Italian, Spanish and French. Colours are taken from each channel's logo. Update check built in.

Inglese, italiano, spagnolo e francese. I colori vengono dal logo di ogni canale. Controllo aggiornamenti integrato.

InstallInstallazione

Debian, Ubuntu, Linux Mint. Download the .deb from the latest release and:

Debian, Ubuntu, Linux Mint. Scarica il .deb dall'ultima release e:

sudo apt install ./xvb_*_all.deb

Then launch XVB from the menu, or type xvb. To update, install the new package over the old one. To remove: sudo apt remove xvb.

Poi apri XVB dal menu, o scrivi xvb. Per aggiornare installa il nuovo pacchetto sopra il vecchio. Per togliere: sudo apt remove xvb.

Without the package, on any distribution:

Senza pacchetto, su qualsiasi distribuzione:

sudo apt install -y libmpv2 python3-tk python3-pil python3-pil.imagetk python3-mpv
git clone https://github.com/JonaDev2026/xvb.git
cd xvb && python3 xvb.py

Legal & responsible useUso legale e responsabile

XVB is a neutral playback tool: it does not provide channels, credentials, or content. Use XVB only with streams you are authorized to access. Avoid piracy or any method to bypass copyright protections.

XVB è uno strumento di riproduzione neutro: non fornisce canali, credenziali o contenuti. Usa XVB solo con flussi a cui sei autorizzato ad accedere. Niente pirateria né metodi per aggirare le protezioni del copyright.
