XVB Player

A media player for Linux Mint 22+, built on libmpv. Videos, music, discs and IPTV in one app.

Lettore multimediale per Linux Mint 22+, basato su libmpv. Video, musica, dischi e IPTV in un'unica app.

Download .debScarica .deb GitHub ♥ DonateDona

FeaturesFunzioni

Videos and musicVideo e musica

Local files with resume, shuffle, repeat and seeking. Open with XVB from the file manager, recent files.

File locali con ripresa, riproduzione casuale, ripetizione e avanzamento. Apri con XVB dal file manager, file recenti.

Covers and postersCopertine e poster

Titles and artwork fetched automatically from TMDB and MusicBrainz, also for untagged music.

Titoli e immagini scaricati in automatico da TMDB e MusicBrainz, anche per la musica senza tag.

DiscsDischi

Video DVDs (not encrypted), data CDs and DVDs, and ISO images. Audio CDs and Blu-ray are not supported.

DVD video (non cifrati), CD e DVD di dati, e immagini ISO. CD audio e Blu-ray non sono supportati.

IPTVIPTV

m3u playlists from file or URL, with an XMLTV guide. Any stream or file can also be opened by URL.

Playlist m3u da file o URL, con guida XMLTV. Qualsiasi stream o file si apre anche da URL.

RecordingRegistrazione

Record live channels, now or scheduled.

Registra i canali in diretta, subito o programmati.

Video and audioVideo e audio

Picture and sound adjustments, tracks, external subtitles with delay and size, screenshots.

Regolazioni di immagine e suono, tracce, sottotitoli esterni con ritardo e dimensione, istantanee.

InstallationInstallazione

Supported system: Linux Mint 22+. Download the .deb from the latest release and run:

Sistema supportato: Linux Mint 22+. Scarica il .deb dall'ultima release ed esegui:

sudo apt install ./xvb_*_all.deb

XVB is then available in the applications menu, or as xvb from a terminal. It starts in the system language: English, Italian, Spanish, French, German, Portuguese or Russian.

XVB si trova poi nel menu delle applicazioni, o come xvb da terminale. Parte nella lingua del sistema: inglese, italiano, spagnolo, francese, tedesco, portoghese o russo.

LegalNote legali

XVB is a neutral playback tool: it does not provide channels, credentials, or content. Use XVB only with streams you are authorized to access. Avoid piracy or any method to bypass copyright protections.

XVB è uno strumento di riproduzione neutro: non fornisce canali, credenziali o contenuti. Usa XVB solo con flussi a cui sei autorizzato ad accedere. Niente pirateria né metodi per aggirare le protezioni del copyright.
