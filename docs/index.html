Container support is not the same as codec support. libmpv uses the multimedia libraries available on the system (commonly FFmpeg); playback depends on the codecs inside the file and the installed build.

Il supporto di un contenitore non equivale al supporto di ogni codec. libmpv utilizza le librerie multimediali disponibili nel sistema (comunemente FFmpeg): la riproduzione dipende dai codec contenuti nel file e dalla build installata.

La compatibilidad con un contenedor no implica compatibilidad con todos los códecs. libmpv utiliza las bibliotecas multimedia disponibles en el sistema (habitualmente FFmpeg); la reproducción depende de los códecs del archivo y de la compilación instalada.

La prise en charge d'un conteneur ne garantit pas celle de tous les codecs. libmpv utilise les bibliothèques multimédias disponibles sur le système (généralement FFmpeg) ; la lecture dépend des codecs présents dans le fichier et de la version installée.

Die Unterstützung eines Containers bedeutet nicht automatisch die Unterstützung jedes Codecs. libmpv verwendet die auf dem System verfügbaren Multimedia-Bibliotheken (häufig FFmpeg); die Wiedergabe hängt von den Codecs in der Datei und der installierten Build-Version ab.

O suporte de um contentor não significa suporte de todos os codecs. O libmpv utiliza as bibliotecas multimédia disponíveis no sistema (normalmente FFmpeg); a reprodução depende dos codecs existentes no ficheiro e da versão instalada.
